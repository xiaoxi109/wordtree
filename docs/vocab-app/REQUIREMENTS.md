# LexiCore 背词 App · 核心需求（讨论版）

> 活文档：随讨论持续补充。当前基于产品源码分析 + 改进原型 v2。

## 一、产品定位

面向中小学英语学习者的**词→文闭环**背词 App：背词 → 标记掌握 → AI 用已掌握词写文章 → 阅读 → 遇生词回流 → 再背。差异化核心是「AI 词汇约束生成」+「错词回流」。

## 二、核心需求（Must-have）

| # | 需求 | 现状 | 问题 |
|---|---|---|---|
| R1 | 词库浏览 + 查词（音标/释义/例句/发音） | ✅ CEFR+人教两个 tab | 词表被拆成两个一级 tab |
| R2 | 掌握标记 | ✅ 词表点星/背词认识/阅读三态 | 入口分散，无引导 |
| R3 | 间隔复习（SRS） | ✅ Leitner 盒调度 | 只复习已掌握，无到期优先提示 |
| R4 | 学新词（新用户冷启动） | ❌ 缺失 | 新用户无已掌握词 → 直接卡死 |
| R5 | AI 课程生成（用已掌握词写作） | ✅ 需配 LLM Key | 门槛高、入口弱、是一级 tab |
| R6 | 阅读 + 点词查词 + 三态回流 | ✅ 完整 | 闭环用户感知为零 |
| R7 | 今日任务引导（今天做什么） | ❌ 缺失 | 首页是词表列表，非任务导向 |
| R8 | 坚持反馈（打卡/统计/成就） | ❌ 缺失 | 无连续天数、无趋势、无成就 |

## 三、信息架构（改进方向）

**现状 5 tab（按内容来源）**：CEFR / 人教 / 学习 / AI / 我
**改进 4 tab（按用户任务）**：

| Tab | 回答 | 内容 |
|---|---|---|
| 今日 | 今天做什么 | 任务卡、进度环、打卡、快捷入口、今日阅读 |
| 词库 | 查词/标掌握 | CEFR+人教合并、搜索、筛选、生成文章入口 |
| 学习 | 背词 | 到期复习 + 学新词 + SRS |
| 我的 | 进度/设置 | 统计、成就、错词本、LLM 配置 |

AI 课程降级为首页「今日阅读」+ 词库「生成文章」，不再占一级 tab。

## 四、关键交互决策（待讨论确认）

- **D1 学新词模式**：学习页加「学新词」，正面回忆→背面释义，评价后自动标记掌握。解决 R4。
- **D2 到期优先**：复习默认到期词优先，UI 明确提示「到期 X 词」。
- **D3 今日阅读入口**：AI 文章从首页进入，不再是常驻 tab。
- **D4 统计闭环**：我的页加本周柱状图、覆盖率、成就徽章。
- **D5 词库合并**：CEFR/人教合并为一个词库 tab，顶部切换来源。

## 五、保留的优质资产（不动）

- Leitner SRS 调度引擎
- AI 词汇约束生成 + 覆盖率度量
- 三态词回流（阅读→错词本→生成）
- 离线发音（Piper）、显示模式切换、滑动手势

## 六、待讨论

- AI 生成对普通用户的门槛（需配 Key）如何降低？
- 学新词的「范围」如何界定（全部未掌握 vs 按 CEFR 等级）？
- 统计/成就的激励强度（是否要推送提醒）？
- 是否保留「听单」独立入口？
